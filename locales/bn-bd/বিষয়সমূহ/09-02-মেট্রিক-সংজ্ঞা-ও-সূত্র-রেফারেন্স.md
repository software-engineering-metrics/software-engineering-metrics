# ৯.২ মেট্রিক সংজ্ঞা ও সূত্র রেফারেন্স

বইয়ের প্রতিটি সূত্র, একটি জায়গায় সংগৃহীত। প্রতিটি এন্ট্রি সেই বিষয়ের নাম দেয় যেখানে সম্পূর্ণ আলোচনা আছে, এর কারচুপির ঝুঁকি ও গার্ডরেলসহ। এটিকে একটি দ্রুত লুকআপ হিসেবে ব্যবহার করুন, বিষয়টি নিজেই এর বিকল্প হিসেবে নয়।

## প্রবাহ মেট্রিক (পর্ব ২)

| মেট্রিক | সূত্র | বিষয় |
| --- | --- | --- |
| প্রবাহ বেগ | প্রতি একক সময়ে সম্পূর্ণ হওয়া প্রবাহ আইটেমের গণনা | ২.৩ |
| প্রবাহ বিতরণ | (একটি প্রবাহ আইটেম ধরনের সম্পূর্ণ আইটেম) / (মোট সম্পূর্ণ আইটেম) x ১০০% | ২.৩ |
| প্রবাহ সময় | একটি প্রবাহ আইটেম মূল্য স্রোতে প্রবেশ করা থেকে এর সরবরাহ পর্যন্ত সময় | ২.৪ |
| প্রবাহ ভার | মূল্য স্রোতে বর্তমানে সক্রিয় বা অপেক্ষারত প্রবাহ আইটেমের গণনা | ২.৪ |
| লিটলের সূত্র | প্রবাহ ভার (প্রক্রিয়াধীন কাজ) = আগমন হার x প্রবাহ সময় (চক্র সময়) | ২.৪, ২.৭ |
| প্রবাহ দক্ষতা | সক্রিয় কাজের সময় / মোট অতিবাহিত সময় x ১০০% | ২.৫ |
| চক্র সময় | পর্যায়ের সময়কালের যোগফল: কোডিং + গ্রহণ + পর্যালোচনা + পরীক্ষা + স্থাপনা | ২.৬ |
| ব্যবহার | আগমন হার / পরিষেবা হার | ২.৭ |
| শতাংশ সম্পূর্ণ ও নির্ভুল (%C/A) | (পুনঃকাজ ছাড়া ডাউনস্ট্রিমে ব্যবহারযোগ্য ইউনিট) / (মোট ইউনিট) x ১০০% | ২.৮ |
| সমষ্টিগত থ্রুপুট ফলন | পর্যায় ১-এর %C/A x পর্যায় ২-এর %C/A x ... x পর্যায় N-এর %C/A | ২.৮ |
| ট্যাক্ট সময় | উপলব্ধ কাজের সময় / সেই সময়ের মধ্যে গ্রাহকের চাহিদা | ২.৮ |
| প্রথম পর্যালোচনার সময় | পুল রিকোয়েস্ট খোলা থেকে প্রথম বাস্তবিক পর্যালোচক প্রতিক্রিয়া পর্যন্ত সময় | ২.৯ |
| স্থাপনার ফ্রিকোয়েন্সি | প্রতি একক সময়ে সফল উৎপাদন স্থাপনার গণনা | ২.১০ |
| পরিবর্তনের জন্য লিড টাইম | প্রথম কমিট থেকে সফল উৎপাদন স্থাপনা পর্যন্ত সময় (মধ্যক ও ৯০তম শতকরা প্রতিবেদন করুন) | ২.১০ |
| পরিবর্তন ব্যর্থতার হার | (ব্যর্থতা সৃষ্টিকারী স্থাপনা) / (মোট স্থাপনা) x ১০০% | ২.১০ |
| ব্যর্থ স্থাপনা পুনরুদ্ধার সময় | ব্যর্থতা শনাক্তকরণ থেকে প্রকৃত পরিষেবা পুনরুদ্ধার পর্যন্ত সময় | ২.১০ |

| মিউট্যান্ট-নিধন হার | (পরীক্ষা স্যুট দ্বারা নিহত মিউট্যান্ট) / (প্রবর্তিত মোট মিউট্যান্ট) x ১০০% | ৪.২ |
| কোড churn | একটি সময় উইন্ডো জুড়ে প্রতি ফাইলে যোগ + পরিবর্তিত + মুছে ফেলা লাইন | ৪.৩ |
| হটস্পট স্কোর | Churn x জটিলতা, প্রতি ফাইলে র‍্যাংকযুক্ত | ৪.৩ |

## পণ্য ও ব্যবসায়িক (পর্ব ৫)

| মেট্রিক | সূত্র | বিষয় |

| পলাতক ত্রুটির হার | (তীব্রতা-ভারযুক্ত পলাতক ত্রুটি) / (সরবরাহ বা সময়ের একক) | ৫.১ |
| প্রাথমিক গ্রহণ | (অন্তত একবার বৈশিষ্ট্যটি চেষ্টা করা ব্যবহারকারী) / (লক্ষ্য শ্রোতা) x ১০০% | ৫.২ |
| ধারণকৃত গ্রহণ | (N সপ্তাহ পরেও বৈশিষ্ট্যটি ব্যবহারকারী) / (প্রাথমিকভাবে চেষ্টা করা ব্যবহারকারী) x ১০০% | ৫.২ |
| একক খরচ | মোট খরচ (মানুষ + অবকাঠামো + টুলিং) / অর্থবহ একক (গ্রাহক, লেনদেন) | ৫.৪ |
| ROI | (মোট সুবিধা − মোট মালিকানা খরচ) / মোট মালিকানা খরচ, একটি পরিসর হিসেবে উপস্থাপিত | ৫.৫ |

## নির্ভরযোগ্যতা, কার্যক্রম, এবং নিরাপত্তা (পর্ব ৬)

| মেট্রিক | সূত্র | বিষয় |
| --- | --- | --- |

| ত্রুটি বাজেট বার্ন হার | ব্যয়িত ত্রুটি বাজেট / বরাদ্দকৃত ত্রুটি বাজেট, একটি নির্দিষ্ট উইন্ডোতে | ৬.১ |
| MTTD | ঘটনার সূচনা থেকে শনাক্তকরণ পর্যন্ত সময় | ৬.২ |
| MTTA | ঘটনার বিজ্ঞপ্তি থেকে স্বীকৃতি পর্যন্ত সময় | ৬.২ |
| MTTR (ঘটনা) | স্বীকৃতি থেকে প্রকৃত পরিষেবা পুনরুদ্ধার পর্যন্ত সময় | ৬.২ |
| অন-কল পেজ বিতরণ | একটি ঘূর্ণায়মান উইন্ডোতে প্রতি ব্যক্তিতে প্রাপ্ত পেজ (দলের গড় নয়) | ৬.৩ |
| দুর্বলতা প্রতিকার-সময় | আবিষ্কার থেকে প্রকৃত প্রতিকার পর্যন্ত সময়, তীব্রতা অনুযায়ী ট্র্যাক করা | ৬.৪ |

## এই সূত্র ব্যবহারের উপর নোট

- **সর্বদা একটি গতি বা আউটপুট সূত্রকে এর গার্ডরেলের সাথে জোড়া বাঁধুন** (বিষয় ১.২): স্থাপনার ফ্রিকোয়েন্সি ও লিড টাইমের সাথে পরিবর্তন ব্যর্থতার হার; সরবরাহ গতির সাথে পলাতক ত্রুটির হার; স্থাপনার কার্যকলাপের সাথে ত্রুটি বাজেট বার্ন।
- **সময়-ভিত্তিক সূত্রের জন্য গড়ের বদলে মধ্যক ও শতকরা ব্যবহার করুন** (বিষয় ১.৬) যদি না একটি সূত্র স্পষ্টভাবে একটি গড়ের জন্য আহ্বান জানায়।
- **প্রতিটি সূত্রের এর গাণিতিক সংজ্ঞার পাশাপাশি একটি নথিভুক্ত উৎস সিস্টেম ও সংগ্রহ পদ্ধতি প্রয়োজন** (বিষয় ১.৫); দুটি দল বিভিন্ন উৎস থেকে একই সূত্র গণনা করলে তুলনাযোগ্য সংখ্যা উৎপাদন করবে না।
- **তীব্রতা ভারকরণ উপরের প্রতিটি সূত্রে স্পষ্টভাবে দেখানো হয়নি** কিন্তু যেখানেই "তীব্রতা-ভারযুক্ত" প্রদর্শিত হয় সেখানে প্রযোজ্য; সম্পূর্ণ শ্রেণীবিন্যাস স্কিমের জন্য প্রাসঙ্গিক বিষয় দেখুন।
