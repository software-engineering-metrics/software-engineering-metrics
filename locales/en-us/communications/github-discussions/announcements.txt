Welcome to Software Engineering Metrics Discussions

Software Engineering Metrics now has GitHub Discussions, a place to ask questions, suggest ideas, and share what you have done with it.

Software Engineering Metrics is a working book about measuring software engineering well, covering the Flow Framework, the SPACE framework, queueing theory, DORA metrics, and how generative AI changes what the numbers mean. It is written for software developer teams, engineering managers, and technical leaders.

## What this means for you

- You can ask questions and get answers from other readers.
- You can suggest topics, fixes, and improvements before anyone writes them.
- You can share how you use the book.

## Where to go for what

- Questions about using the book: Q&A
- Suggestions for new or changed topics: Ideas
- Quick community votes: Polls
- Things you have built or tried with the book: Show and tell
- Everything else: General
- Errors, broken links, or typos: Issues (https://github.com/software-engineering-metrics/software-engineering-metrics/issues)
