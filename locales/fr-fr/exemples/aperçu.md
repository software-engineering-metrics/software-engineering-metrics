# Exemples

De petits exemples concrets qui montrent les idées du livre en situation. Ils
sont illustratifs, pas exhaustifs. Les modèles complets figurent dans les
annexes ([sujet 9.4, Modèles](../sujets/09-04-modeles.md)).

## Contenu

- **[exemple-charte-de-métriques.md](exemple-charte-de-métriques.md)** : une charte de
  métriques remplie, du type décrit dans le
  [sujet 1.4](../sujets/01-04-gouvernance-et-propriete-des-metriques.md).
- **[exemple-spécification-de-tableau-de-bord.md](exemple-spécification-de-tableau-de-bord.md)** : une spécification
  de tableau de bord détaillée pour un tableau de bord de métriques de
  livraison, selon le
  [sujet 8.1](../sujets/08-01-concevoir-un-tableau-de-bord-de-metriques-dingenierie.md).
- **Squelette de sujet** : pour commencer un nouveau sujet, copiez le
  [modèle de sujet](../contribuer/modèle-de-sujet.md).

## Utilisation

Copiez un exemple, remplacez le contenu par le vôtre et conservez la forme.
L'essentiel est la structure et le niveau de détail, pas les valeurs
particulières.
