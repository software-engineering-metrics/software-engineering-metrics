# 9.3 チェックリスト

すぐに使えるクイックリファレンスのチェックリスト。一つをあなた自身のプロセスにコピーして適応させてください。重要なのはカバレッジであり、正確な言い回しではありません。

## 新しい指標のレビューのチェックリスト(ダッシュボードにどんな指標を追加する前にも)

- [ ] その指標が情報を与える決定に名前がついている(第1.1章)
- [ ] その指標が診断的あるいは評価的として書面で分類されている(第1.1章)
- [ ] インセンティブがかかっているなら、同時にガードレール指標が定義されている(第1.2章)
- [ ] ゲーミングのベクトルに名前がつけられている:合理的なチームはどうやって本物の成果を改善することなくこの数字を良く見せるだろうか(第1.2章)
- [ ] その指標がインプット、アウトプット、あるいは成果として分類されている(第1.3章)
- [ ] その指標に名前のついた所有者と文書化された情報源のシステムと収集方法がある(第1.4章、第1.5章)
- [ ] 基盤となるデータが歪んでいる場合、その指標が平均ではなく中央値あるいはパーセンタイルを使う(第1.6章)
- [ ] その指標が個人の評価に決して使われないか、その使用が別途明示的に開示されている(第1.1章)

## ダッシュボード開始のチェックリスト

- [ ] ダッシュボードに一つの名前のついた特定の聴衆と決定がある(第8.1章)
- [ ] インセンティブのかかったすべての指標がそのガードレールと同じビューに現れる(第1.2章、第8.1章)
- [ ] 述べられ見える例外が文書化されていない限り軸がゼロから始まる(第1.6章)
- [ ] 単一のスナップショットではなく時間をかけたトレンドが示されている(第1.6章)
- [ ] ダッシュボードに名前のついた所有者とレビューのペースがある(第1.4章)
- [ ] 関連する場合、ダッシュボードが何のためのものではないかを宣言する見える声明がある(第1.1章)
- [ ] 壊れたパイプラインが静かに最新のものとして表示されないよう、データの情報源に基本的なヘルスチェックがある(第1.5章)

## 指標プログラム展開のチェックリスト

- [ ] 目的と明示的な非目標が、反応的にではなく開始前に伝えられている(第8.3章)
- [ ] 測定される人々が指標の選択に巻き込まれた(第8.3章)
- [ ] プログラムは、コミットされた最小限の証明期間とともに診断専用のモードで始まる(第8.3章)
- [ ] 将来のどんな誤用のインシデントにも速く見える対応のプロトコルが存在する(第8.3章)
- [ ] 義務づけられたものではなく本物に志願した試験チームが選ばれている(第8.5章)
- [ ] 計測が始まる前に基礎的なガバナンス(憲章、所有権、診断ポリシー)が整っている(第1.4章、第8.5章)

## インシデントと事後検証のチェックリスト

- [ ] 事後検証は個人ではなくシステムを調査する(第6.2章)
- [ ] 重大度は文書化された標準化された基準に対して分類された(第6.2章)
- [ ] 検知、確認、解決の時間が別々に記録されている(第6.2章)
- [ ] アクションアイテムは具体的で、割り当てられ、完了まで追跡されている(第6.2章)
- [ ] 事後検証は個人の結果への恐れなしに共有されている(第6.2章、第8.3章)

## AI時代の指標監査のチェックリスト

- [ ] 各ダッシュボードの指標が「AI支援を大いに使っているが以前より多くの本物の価値を生み出していないチームはここで改善された読み取り値を示すだろうか」に対してテストされている(第7.1章)
- [ ] AI支援のデプロイ頻度あるいはコミットの量のどんな上昇と並んでも変更失敗率と欠陥率が見直されている(第7.1章)
- [ ] AI生成のコードの量が変化するにつれてレビューの容量と深さが監視されている(第7.1章)
- [ ] 歴史的な欠陥率の関係が依然として成り立っているかどうかを仮定するのではなくテストするために、エスケープした欠陥がAI支援のレベルによってタグ付けされている(第7.1章、第7.3章)
- [ ] 「正しく見える」欠陥に抵抗する検出方法(ミューテーションテスト、プロパティベースのテスト)がAIを多用するコードパスについて整っている(第7.3章)
- [ ] 指標憲章が、検討されないまま漂流させるのではなく、この変化のために明示的に見直され更新されている(第1.4章、第7.1章)

## 指標プログラム監査のチェックリスト(年次)

- [ ] すべての指標が依然として名前のついた所有者を持っている(第1.4章)
- [ ] 少なくとも一つの指標が、もはやその価値に見合わなくなったなら前のサイクルで廃止されている(第1.1章)
- [ ] 5次元の成熟度の評価が正直に実施され、平均ではなく最小値で採点されている(第8.4章)
- [ ] どの指標も、明示的で開示された決定なしに診断的な使用から評価的な使用に漂流していない(第1.1章)
- [ ] 定義が漂流について実際の計測に対して抜き打ちで確認されている(第1.2章、第2.4章、第5.1章、第6.2章、第6.4章)
- [ ] 主要なダッシュボードの成果対アウトプットの比率が計算され見直されている(第7.4章)
