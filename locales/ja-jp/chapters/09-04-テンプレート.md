# 9.4 テンプレート

繰り返される文書のためのコピー&ペーストできるテンプレート。最初の二つの実例として記入された例は`docs/examples/`にあります。

## 指標憲章のテンプレート

```markdown
# 指標憲章:[チームあるいは指標セットの名前]

- **チーム:** [所有するチーム]
- **所有者:** [名前のついた人物あるいは役割]
- **見直し:** [ペース、例:四半期ごと]

## 目的

[1、2文:この憲章が統治するもの、そしてなぜ。]

## 私たちが追跡するもの

| 指標 | 真実の情報源 | 所有者 |
| --- | --- | --- |
| [指標] | [システム] | [名前のついた所有者] |

## 非目標

[これらの指標が何に使われないかの明示的な声明、例:個人のパフォーマンス評価、文脈なしのチーム横断のランキング。]

## ガードレール

[インセンティブのかかった各指標について、その対になったガードレールと、それがどのゲーミングのパターンを捕捉するかに名前をつけてください。]

## レビューのペース

[この憲章がいつどのように見直されるか。何が指標の廃止を引き起こすか。]
```

## ダッシュボード仕様のテンプレート

```markdown
# ダッシュボード仕様:[ダッシュボードの名前]

## 聴衆

[このダッシュボードが誰のためで、どの決定に情報を与えるか。個人の評価のためでない場合は明示的に述べてください。]

## タイル(表示順)

1. **[指標の名前]**、[時間枠]、[チャートの種類]。[特定の視覚化のメモ:軸のルール、注釈。]
2. ...

## 視覚化のルール

- 他に述べられていない限り軸はゼロから始まり、その例外はタイルに文書化されています。
- [他のどんなプロジェクト特有の正直さのルールも。]

## 更新のペース

[各タイルがどれだけ頻繁に更新されるか、そしてどの情報源からか。]

## このダッシュボードが意図的に除外するもの

[意図的に除外されたものと、その理由に名前をつけてください。例:個人の活動件数。]
```

## 指標レビュー会議の議題のテンプレート

```markdown
# 指標レビュー:[日付]

## 参加者

[名前と役割]

## レビューされた指標

各指標について:
- 現在の読み取り値とトレンド
- 通常の変動の範囲を超えるどんな動きも(第1.6章)
- 対になったガードレールの状況、該当する場合
- この読み取り値が情報を与える決定、もしあれば

## 提案された新しい指標

[それぞれを新しい指標のレビューのチェックリスト、第9.3章にたどってください。]

## 廃止が検討された指標

[どの指標が過去2サイクルで決定に情報を与えていないでしょうか。]

## アクションアイテム

| 項目 | 所有者 | 期限 |
| --- | --- | --- |
| | | |
```

## 非難のない事後検証のテンプレート

```markdown
# 事後検証:[インシデントの名前]、[日付]

## 概要

[1段落:何が起きたか、ユーザーへの影響、期間。]

## タイムライン

- 検知:[時刻、どう検知されたか]
- 確認:[時刻、誰が対応したか]
- 解決:[時刻、何がそれを修正したか]

## 重大度

[文書化された基準に対する分類、第6.2章。]

## 根本原因

[個人の問いとしてではなくシステムの問いとして枠組みづけられた、何がこれが起きることを許したか。]

## うまくいったこと

[対応においてうまく機能した特定のこと。]

## アクションアイテム

| 項目 | 所有者 | 期限 |
| --- | --- | --- |
| | | |

## フォローアップ

[次のレビューサイクルに従って、アクションアイテムが完了まで追跡されたことの確認。]
```

## ROI事例のテンプレート

```markdown
# ROI事例:[取り組みの名前]

## コスト(総所有コスト、第5.5章)

- 事前:[開発コスト]
- 継続的:[保守、インフラ、サポート、年あたり]
- 機会費用:[この容量が他に何をできたか]

## 利益(文書化された証拠、第5.1章から第5.3章)

- [利益1]、[データの情報源]によって裏付けられる
- [利益2]、[データの情報源]によって裏付けられる

## 範囲と仮定

- 保守的なケース:[数字]
- 楽観的なケース:[数字]
- 範囲を動かす主要な仮定:[それに名前をつける]

## 検討され除外された交絡因子

[他に予測された利益を説明できるものは何か、そしてそれがなぜ除外された、あるいは考慮されたか。]

## 完了後の確認(取り組みが完了した後に記入)

- 実際の成果:[数字]
- 予測された範囲と比較して:[上回る/範囲内/下回る]
- これが次の見積もりのために私たちに教えること:[メモ]
```
