# 변경 이력

책과 그 도구의 주요 변경이다. 최신 항목이 맨 위에 있다. 날짜는 ISO 8601(YYYY-MM-DD)을 쓴다.

## [Unreleased]

### Changed

- 네덜란드어(`nl-nl`): 주제 9.0, 9.3, 9.4에 남아 있던 영어 제목과 슬러그를 번역했다(`bijlagen`, `controlelijsten`, `sjablonen`).
- 웨일스어(`cy-001`, `cy-gb`): 용어를 TermCymru에 맞췄다. `risg`(위험, `perygl` 대신, 성 일치 포함), `cyfnewidiad`(트레이드오프),
  `dangosydd rhagfynegi`와 `dangosydd ôl-fynegi`(선행 지표와 후행 지표, `hwyrfrydig` 대신), `cynhwysedd`(용량), `dosraniad`(분포),
  `cydberthynas`(상관), 주제 1.3의 산출물에 `allbwn`, `cyfradd gadael staff`(이직률). 일치시키려고 주제 슬러그 네 개의 이름을 바꿨다.
- 사이트: `@lilydesignsystem/svelte-picker-bar`를 0.2.0으로 올렸다. 헤더 바에 검색 피커가 추가되며, 기존 `/?<query>` 사이트 검색으로 제출한다.
- `scripts/generate-sitemap.mjs`를 추가했다. `pnpm build`의 끝에서 실행되어 미리 렌더링한 페이지로 `sitemap.xml`을 쓴다
  (정규 로케일 URL만, 두 글자 별칭 중복 없음). 이로써 `robots.txt`의 `Sitemap:` 줄이 해결된다.
- `AGENTS.md`는 이제 짧은 색인이다. 세부는 `AGENTS/layout.md`, `style.md`, `locales.md`, `workflow.md`로 옮겼다.
- 문서 정리: 27개 로케일, 로케일별 섹션 디렉터리 이름, 새 도구에 맞춰 `AGENTS.md`, `index.md`, 생성되는 README 로케일 텍스트, `spec/index.md`, `spec/locales.md`,
  사이트의 `AGENTS.md`와 `README.md`를 갱신했다. `CLAUDE.md`(`AGENTS.md`를 가리키는 포인터)를 추가하고, 두 에이전트 스킬의 낡은 `docs/` 경로를 고치고,
  `skills/`를 `.claude/skills/`의 정본 사본으로 만들었다(테스트가 검사한다).
- 사이트의 `static/`에 `llms.txt`와 `llms.json`(제공하는 모든 로케일과 주제의 AI 에이전트 색인)을 추가했다. `tools/gen_llms.py`(`just llms`)가 생성하고 테스트가 검사한다.
- 사이트 홈페이지: "아홉 개의 부" 타일 목록을 모든 부와 주제의 "목차" 중첩 목록으로 바꾸고, "굿하트의 법칙, 어디서나" 섹션을 없앴다.
- 모든 로케일에서 책 본문의 "chapter"를 "topic"으로 바꿨다(예: "주제 2.1", "이 부의 주제"). 각 언어 고유의 "topic" 단어(`tema`, `sujet`, `Thema`, `тема`, `主題` 등)를 쓰며,
  명세, 도구가 생성하는 텍스트, 사이트 UI 문자열에도 적용했다. 파일 이름, URL, 섹션 키는 그대로다.
- `locales/` 아래 모든 섹션 디렉터리 이름을 번역했다. `chapters/`는 `topics/`가 되었고(다른 로케일에서는 그 번역어, 예: `temas/`, `sujets/`, `themen/`),

- 번역된(철자 파생이 아닌) 로케일을 위한 인프라를 새 `spec/locales-for-global-sharing-with-svelte/` 하위 명세에 따라 추가했다.
  `tools/gen_locale_peer_ids.py`는 모든 콘텐츠 파일에 로케일 간에 동일한 `.locale-peer-id` 사이드카를 부여한다. 미래의 번역 로케일(자기 고유 문자의 슬러그를 가진)은
  슬러그로 맞추는 대신 이를 써서 "이 페이지의 로케일 X 판"을 해결할 수 있다. `tests/validate.py`는 모든 사이드카가 있고 일치하는지 검사한다.
  `spec/locales.md`는 계획된 번역 로케일 열 개(아랍어, 벵골어, 웨일스어, 스페인어, 프랑스어, 힌디어, 인도네시아어, 포르투갈어, 러시아어, 우르두어, 중국어 - 중국)를 기록한다.
  사이트에서는 `scripts/locales.mjs`에 `LOCALE_LABELS`/`localeLabel()`(계획된 모든 로케일의 표시 이름, 라우팅 전에 준비됨)과 `sortedLocaleEntries()`(미래의 로케일 목록이 써야 할 정렬 순서)가 생겼고,
  `src/lib/i18n.js`는 모든 `.svelte` 컴포넌트가 이전에 영어로 하드코딩하던 UI 크롬 문자열(내비, 사이드바, 페이저, 피커, 푸터, 건너뛰기 링크)을 뽑아
  `ui(locale)`로 흘려보내며, 자체 번역이 없는 로케일은 영어로 되돌아간다.
- 사이트의 손으로 만든 로케일 전용 헤더 컨트롤을 [Lily Design System](https://lilydesignsystem.com/)의 `@lilydesignsystem/svelte-picker-bar`로 바꿨다.
  진짜 테마 피커(새 `static/assets/themes/{light,dark}.css`를 통한 라이트/다크), 진짜 로케일 피커(기본의 lang/dir 전용 동작 대신 이 사이트의 URL 기반 라우팅에 연결),
  텍스트 크기 피커(Lily의 7단계 척도), 공유 피커(이메일, Mastodon, 링크 복사)다. `@lilydesignsystem/svelte-{theme,locale,text-size,share}-picker`를 `^0.1.2`로,
  `@lilydesignsystem/svelte-headless`를 `^0.2.0`으로 `pnpm-workspace.yaml` overrides를 통해 고정해, `svelte-picker-bar` 0.1.0 자체의 의존성 범위에 있던 실제 발행 버그를 피했다
  (각 피커의 `CHANGELOG.md`의 "0.1.2"와 이 사이트의 `AGENTS.md`를 보라).
- 홈페이지의 통계 줄(부/주제/"Free Always")과 그 "How to read it" 섹션을 없애고, "Browse the nine parts" 카드 그리드를 평범한 글머리 기호 목록으로 바꿨다.
