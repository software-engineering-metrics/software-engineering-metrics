# ตัวอย่าง: กฎบัตรตัวชี้วัดสำหรับทีมแพลตฟอร์มการชำระเงิน

ตัวอย่างกฎบัตรตัวชี้วัดที่ใช้งานได้จริง ซึ่งเป็นเอกสารหน้าเดียวชนิดที่อธิบายใน
[หัวข้อ 1.4 ธรรมาภิบาลและความเป็นเจ้าของตัวชี้วัด](../หัวข้อ/01-04-การกำกับดูแลและความเป็นเจ้าของตัวชี้วัด.md)
จุดสำคัญคือรูปทรง: วัตถุประสงค์ที่ระบุไว้ สิ่งที่ไม่ใช่เป้าหมายอย่างชัดเจน ผู้รับผิดชอบที่มีชื่อ
และรอบการทบทวน กฎบัตรที่สั้นเพียงนี้ตั้งใจให้ถูกอ่าน ไม่ใช่ถูกเก็บเข้าแฟ้ม

- **ทีม:** แพลตฟอร์มการชำระเงิน
- **ผู้รับผิดชอบ:** ผู้จัดการวิศวกรรมแพลตฟอร์ม
- **ทบทวน:** ทุกไตรมาส ในการประชุมทบทวนแพลตฟอร์ม

## วัตถุประสงค์

กฎบัตรนี้กำกับตัวชี้วัดที่ทีมแพลตฟอร์มการชำระเงินติดตามเกี่ยวกับการส่งมอบและความน่าเชื่อถือของตนเอง
มีขึ้นเพื่อให้ทุกคน ทั้งในและนอกทีม เห็นว่าวัดอะไร ทำไม และไม่ได้มีไว้เพื่ออะไร

## สิ่งที่เราติดตาม

| ตัวชี้วัด | แหล่งข้อมูลหลัก | ผู้รับผิดชอบ |
| --- | --- | --- |
| ความถี่ในการ deploy | CI/CD pipeline | หัวหน้าแพลตฟอร์ม |
| Lead time สำหรับการเปลี่ยนแปลง | Git พร้อม deployment pipeline | หัวหน้าแพลตฟอร์ม |
| อัตราความล้มเหลวของการเปลี่ยนแปลง | ตัวติดตามเหตุการณ์ผิดปกติ แท็กตามการ deploy | หัวหน้าเวรเฝ้าระวัง |
| เวลากู้คืนจากการ deploy ที่ล้มเหลว | ตัวติดตามเหตุการณ์ผิดปกติ | หัวหน้าเวรเฝ้าระวัง |
| ความหน่วง API ที่ P99 (SLI) | แพลตฟอร์ม observability | หัวหน้า SRE |
| การเผางบประมาณข้อผิดพลาด | แพลตฟอร์ม observability | หัวหน้า SRE |

## สิ่งที่ไม่ใช่เป้าหมาย

ตัวชี้วัดเหล่านี้จะไม่ถูกนำไปใช้ ไม่ว่าเดี่ยวหรือรวมกัน เพื่อจัดอันดับวิศวกร ประเมินผลการปฏิบัติงาน
หรือเปรียบเทียบทีมนี้กับแผนงานของทีมอื่น โดยไม่เปรียบเทียบขอบเขตงาน จำนวนบุคลากร
และวุฒิภาวะของระบบไปพร้อมกัน การใช้นอกเหนือจากวัตถุประสงค์ที่ระบุข้างต้นต้องได้รับการอนุมัติจาก
ผู้อำนวยการฝ่ายวิศวกรรมและตัวทีมเอง

## Guardrail

ตัวชี้วัดข้างต้นทุกตัวที่มีแรงจูงใจผูกอยู่จะถูกจับคู่กับ guardrail Lead time สำหรับการเปลี่ยนแปลง
ถูกเฝ้าดูควบคู่กับอัตราความล้มเหลวของการเปลี่ยนแปลง ทีมจึงปรับปรุงตัวเลขความเร็วด้วยการส่งมอบ
การเปลี่ยนแปลงที่เสี่ยงกว่าเดิมไม่ได้ ความถี่ในการ deploy ถูกเฝ้าดูควบคู่กับการเผางบประมาณข้อผิดพลาด
ด้วยเหตุผลเดียวกัน

## รอบการทบทวน

ทีมทบทวนกฎบัตรนี้ทุกไตรมาส ตัวชี้วัดที่ไม่ได้เปลี่ยนการตัดสินใจใดเลยในสองไตรมาสติดต่อกัน
เป็นตัวเลือกสำหรับการปลดระวาง
