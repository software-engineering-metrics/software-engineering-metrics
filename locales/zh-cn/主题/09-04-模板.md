# 9.4 模板

用于反复使用文档的可复制粘贴模板。前两份的完整填写示例，存放在英文版的`docs/examples/`目录中。

## 指标章程模板

```markdown
# 指标章程：[团队或指标集名称]

- **团队：**[负责团队]
- **所有者：**[具名人员或角色]
- **审阅：**[节奏，例如按季度]

## 目的

[一两句话：这份章程治理什么，为什么。]

## 我们跟踪什么

| 指标 | 权威数据来源 | 所有者 |
| --- | --- | --- |
| [指标] | [系统] | [具名所有者] |

## 非目标

[明确声明这些指标不用于什么，例如个人绩效评估、没有背景信息的跨团队排名。]

## 护栏

[对每一项被激励的指标，指出它配对的护栏，以及它捕捉的是哪种操纵模式。]

## 审阅节奏

[这份章程何时、如何被重新审视；什么会触发一项指标的退役。]
```

## 仪表盘规格模板

```markdown
# 仪表盘规格：[仪表盘名称]

## 受众

[这份仪表盘是为谁准备的，它为哪个决策提供依据。如果不用于个人评估，明确声明。]

## 图块（按显示顺序）

1. **[指标名称]**，[时间窗口]，[图表类型]。[任何具体的可视化说明：坐标轴规则、注释。]
2. ……

## 可视化规则

- 除非另有说明，坐标轴从零开始，例外情况在该图块上记录。
- [任何其他项目特定的诚实性规则。]

## 刷新节奏

[每个图块多久更新一次，数据来自哪里。]

## 这份仪表盘刻意排除了什么

[点名任何被有意排除的内容，以及为什么，例如个人活动计数。]
```

## 指标评审会议议程模板

```markdown
# 指标评审：[日期]

## 参会者

[姓名和角色]

## 被评审的指标

对每一项指标：
- 当前读数和趋势
- 任何超出正常变异范围的变动（第1.6章）
- 配对护栏的状态，如果适用
- 这个读数为哪个决策提供了依据，如果有的话

## 提议的新指标

[用新指标评审清单（第9.3章）逐一检验每一项。]

## 被考虑退役的指标

[哪些指标在过去两个周期里没有为任何决策提供依据？]

## 行动项

| 事项 | 负责人 | 截止日期 |
| --- | --- | --- |
| | | |
```

## 无责事后分析模板

```markdown
# 事后分析：[事件名称]，[日期]

## 摘要

[一段话：发生了什么，用户影响，持续时间。]

## 时间线

- 检测：[时间，如何被检测到]
- 确认：[时间，谁做出了响应]
- 解决：[时间，是什么修复了它]

## 严重程度

[对照有文档记录的标准进行分类，第6.2章。]

## 根本原因

[是什么让这件事得以发生，被定位为一个系统问题，而不是一个个人问题。]

## 哪些方面做得好

[响应中起作用的具体事项。]

## 行动项

| 事项 | 负责人 | 截止日期 |
| --- | --- | --- |
| | | |

## 后续跟进

[确认行动项已被跟踪到完成，依据下一个审阅周期。]
```

## 投资回报论证模板

```markdown
# 投资回报论证：[举措名称]

## 成本（总拥有成本，第5.5章）

- 前期：[开发成本]
- 持续：[维护、基础设施、支持，每年]
- 机会成本：[这份产能原本还能做什么]

## 收益（有文档记录的证据，第5.1章至第5.3章）

- [收益1]，由[数据来源]提供证据
- [收益2]，由[数据来源]提供证据

## 范围与假设

- 保守情形：[数字]
- 乐观情形：[数字]
- 驱动这个范围的关键假设：[指出它]

## 已考虑并排除的混淆因素

[还有什么可能解释预测的收益，以及它为什么被排除或被核算在内。]

## 完成后核查（在举措完成后填写）

- 实际结果：[数字]
- 与预测范围相比：[高于 / 落在范围内 / 低于]
- 这为下一次估算教会了我们什么：[备注]
```
