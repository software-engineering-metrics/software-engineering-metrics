# 8.0 Einführung zu Teil 8: Ein Metrikprogramm aufbauen

Jeder vorangegangene Teil dieses Buches hat eine Metrikfamilie eingehend behandelt: was zu messen ist, wie es manipuliert wird, und welche Leitplanke diese Manipulation fängt. Dieser letzte substanzielle Teil wendet sich von *was* gemessen werden soll zu *wie* das organisatorische Programm aufgebaut und betrieben wird, das all dies in die Praxis umsetzt. Eine Organisation, die jedes Thema dieses Buches gelesen hat, aber nie das Dashboard, die Tooling-Entscheidung, den Rollout-Plan, und die Reife-Roadmap baut, die dieser Teil abdeckt, hat exzellentes Wissen und kein funktionierendes Metrikprogramm. Dieser Teil existiert, um diese Lücke zu schließen.

Die fünf Themen hier folgen der natürlichen Sequenz, tatsächlich ein Metrikprogramm von Grund auf aufzubauen, oder eines zu korrigieren, das von den Prinzipien dieses Buches abgedriftet ist. Thema 8.1 behandelt speziell Dashboard-Design, wobei die vielen Metriken aus Teilen 1 bis 7 in ein kohärentes, ehrliches, nutzbares Set von Ansichten verwandelt werden. Thema 8.2 behandelt die Bauen-oder-Kaufen-Entscheidung, der jede Organisation schließlich für ihr Metrik-Tooling gegenübersteht. Thema 8.3 ist das menschenzentrierteste dieses Buches, das direkt die Furcht adressiert, die ein Metrik-Rollout provozieren kann, und wie verhindert wird, dass diese Furcht genau die Daten korrumpiert, von denen das Programm abhängt, die Warnungen aus Thema 1.2 durchgängig widerhallend. Thema 8.4 konsolidiert das Fünf-Stufen-Reifegradmodell jedes Themas in ein einzelnes, kohärentes Framework für organisatorische Selbstbewertung. Thema 8.5 schließt den substanziellen Inhalt des Buches mit einer konkreten, sequenzierten Einführungs-Roadmap ab.

Für große Teams ist dieser Teil, wo die Ideen dieses Buches entweder dauerhafte organisatorische Praxis werden oder ein intellektuell befriedigendes Dokument bleiben, das niemand tatsächlich umsetzt. Konzerne und Behörden, mit ihrem Maßstab und ihrem echten Risiko, dass Halbmaßnahmen schlechtere Ergebnisse produzieren als gar kein Metrikprogramm (die zentrale Warnung aus Thema 8.3), verlassen sich auf die praktische Anleitung dieses Teils, um die Prinzipien dieses Buches in einen Rollout zu übersetzen, der tatsächlich funktioniert, statt einen, der Furcht provoziert, manipulierte Daten produziert, und jede schlimmste Annahme jeder Skeptikerin und jedes Skeptikers darüber bestätigt, was ein Metrikprogramm einem Team antut.

## Themen in diesem Teil

- **8.1 Ein Engineering-Metrik-Dashboard gestalten:** Die vielen Metriken dieses Buches in ein kohärentes, ehrliches, handlungsfähiges Set von Ansichten für unterschiedliche Zielgruppen verwandeln.
- **8.2 Tooling-Landschaft: Bauen gegen Kaufen:** Die echten Abwägungen bei der Wahl oder dem Bau von Metrik-Tooling, und wie entschieden wird.
- **8.3 Metriken einführen, ohne Furcht zu züchten:** Das einzige wichtigste praktische Thema in diesem Teil, darüber, zu verhindern, dass ein Metrikprogramm genau das Manipulationsverhalten provoziert, vor dem dieses Buch durchgängig gewarnt hat.
- **8.4 Reifegradmodell für Engineering-Metrikprogramme:** Ein konsolidiertes, fünfstufiges Reifegrad-Framework, das das individuelle Modell jedes Themas zusammenführt.
- **8.5 Eine inkrementelle Einführungs-Roadmap:** Ein konkreter, gestufter, sequenzierter Pfad von dort, wo die Organisation derzeit steht, zu einem reifen Metrikprogramm.

## Wie diese Themen zusammenhängen

Thema 8.1 ist, wo die abstrakten Metrikfamilien aus Teilen 1 bis 7 zu einem konkreten Artefakt werden, einem Dashboard, das echte Menschen tatsächlich ansehen. Thema 8.2 behandelt die Tooling-Entscheidung, von der dieses Dashboard abhängt. Thema 8.3 ist das Scharnierthema dieses Teils: es adressiert die menschlichen und organisatorischen Dynamiken, die bestimmen, ob alles, was dieses Buch empfohlen hat, tatsächlich vertrauenswürdige Daten produziert oder still durch Furcht korrumpiert wird, direkt zurückgebunden an die Goodharts-Gesetz-Warnung aus Thema 1.2, die dieses gesamte Buch eröffnete. Thema 8.4 konsolidiert das Bewertungs-Framework, das jedes vorherige Thema bereits individuell angeboten hat, und Thema 8.5 verwandelt diese konsolidierte Bewertung in einen tatsächlichen, sequenzierten Plan.

Dieser Teil ist auch, wo die Anhänge dieses Buches (Teil 9) am direktesten nützlich werden: die Vorlagen (Thema 9.4) und Checklisten (Thema 9.3), die dieses Buch liefert, sind speziell gebaut, um die Rollout-Arbeit zu unterstützen, die dieser Teil beschreibt, und die konsolidierte Reifegrad-Selbstbewertung (Thema 9.5) ist der direkte Begleiter zum Framework aus Thema 8.4. Dieser Teil sollte als Antwort dieses Buches auf die Frage gelesen werden, die jeder frühere Teil implizit aufwarf: jetzt, da bekannt ist, was gemessen werden soll und wie es ehrlich gemessen wird, wie wird tatsächlich die Organisation aufgebaut, die das tut, nachhaltig, im großen Maßstab, ohne dass der gesamte Aufwand unter genau dem Manipulationsdruck zusammenbricht, vor dem Thema 1.2 von der allerersten Seite an warnte.
