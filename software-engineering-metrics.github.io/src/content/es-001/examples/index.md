# Ejemplos

Ejemplos pequeños y concretos que muestran las ideas del libro en uso.
Estos son ilustrativos, no exhaustivos. Las plantillas completas viven en
los apéndices
([tema 9.4, Plantillas](../chapters/09-04-plantillas.md)).

## Contenido

- **[ejemplo-carta-de-métricas.md](metrics-charter-example.md)**: una carta
  de métricas rellenada, del tipo descrito en el
  [tema 1.4](../chapters/01-04-gobernanza-y-propiedad-de-las-métricas.md).
- **[ejemplo-especificación-de-panel.md](dashboard-spec-example.md)**: una
  especificación de panel trabajada para un panel de métricas de entrega,
  siguiendo el
  [tema 8.1](../chapters/08-01-diseñar-un-panel-de-métricas-de-ingeniería.md).
- **Esqueleto de tema**: para empezar un tema nuevo, copia la
  [plantilla de tema](../contributing/chapter-template.md).


## Cómo usarlos

Copia un ejemplo, reemplaza el contenido con el tuyo propio, y mantén la
forma. Lo que importa es la estructura y el nivel de detalle, no los
valores específicos.
