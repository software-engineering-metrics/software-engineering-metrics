# Esimerkit

Pieniä, konkreettisia esimerkkejä, jotka näyttävät kirjan ajatukset käytössä.
Ne ovat havainnollisia, eivät kattavia. Täydet mallipohjat ovat liitteissä
([aihe 9.4, Mallipohjat](../chapters/09-04-mallipohjat.md)).

## Sisältö

- **[esimerkki-mittarien-peruskirja.md](metrics-charter-example.md)** :
  täytetty mittarien peruskirja, sellainen kuin
  [aiheessa 1.4](../chapters/01-04-mittarien-hallinta-ja-omistajuus.md) kuvataan.
- **[esimerkki-mittariston-maarittely.md](dashboard-spec-example.md)** :
  läpikäyty toimitusmittariston määrittely
  [aiheen 8.1](../chapters/08-01-ohjelmistotuotannon-mittariston-suunnittelu.md) mukaan.
- **Aiheen runko** : kun aloitat uuden aiheen, kopioi
  [aihepohja](../contributing/chapter-template.md).

## Näiden käyttö

Kopioi esimerkki, korvaa sisältö omallasi ja säilytä muoto. Tärkeää ovat rakenne
ja tarkkuuden taso, ei yksittäiset arvot.
