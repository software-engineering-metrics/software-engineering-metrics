# 9.3 Tarkistuslistat

Käyttövalmiit pikatarkistuslistat. Kopioi yksi omaan prosessiisi ja mukauta
sitä. Tarkoitus on kattavuus, ei täsmällinen sanamuoto.

## Uuden mittarin katselmoinnin tarkistuslista (ennen kuin lisäät mittarin mihinkään mittaristoon)

- [ ] Mittarilla on nimetty päätös, jota se tukee (aihe 1.1)
- [ ] Mittari on luokiteltu diagnostiseksi tai arvioivaksi, kirjallisesti
      (aihe 1.1)
- [ ] Jos mittari on kannustettu, suojakaidemittari on määritelty samalla
      kertaa (aihe 1.2)
- [ ] Pelaamisen tapa on nimetty: miten järkevä tiimi saisi tämän luvun
      näyttämään hyvältä parantamatta todellista tulosta (aihe 1.2)
- [ ] Mittari on luokiteltu syötteeksi, tuotokseksi tai tulokseksi (aihe 1.3)
- [ ] Mittarilla on nimetty omistaja sekä dokumentoitu lähdejärjestelmä ja
      keruutapa (aiheet 1.4, 1.5)
- [ ] Mittari käyttää mediaania tai persentiiliä, ei keskiarvoa, jos
      taustalla oleva data on vinoa (aihe 1.6)
- [ ] Mittaria ei koskaan käytetä yksilöiden arviointiin, tai tuo käyttö on
      erikseen ja nimenomaisesti ilmoitettu (aihe 1.1)

## Mittariston julkaisun tarkistuslista

- [ ] Mittaristolla on yksi nimetty, täsmällinen yleisö ja päätös
      (aihe 8.1)
- [ ] Jokainen kannustettu mittari on samassa näkymässä suojakaiteensa
      kanssa (aiheet 1.2, 8.1)
- [ ] Akselit alkavat nollasta, ellei näkyvää, dokumentoitua poikkeusta ole
      ilmoitettu (aihe 1.6)
- [ ] Näytetään trendi ajan yli, ei yksittäistä tilannekuvaa (aihe 1.6)
- [ ] Mittaristolla on nimetty omistaja ja katselmointirytmi (aihe 1.4)
- [ ] Näkyvä ilmoitus kertoo, mihin mittaristoa ei ole tarkoitettu, jos
      relevanttia (aihe 1.1)
- [ ] Tietolähteillä on perustason terveystarkistukset, jotta rikkinäinen
      putki ei hiljaa näytä ajantasaiselta (aihe 1.5)

## Mittariohjelman käyttöönoton tarkistuslista

- [ ] Tarkoitus ja nimenomaiset ei-tavoitteet kommunikoidaan ennen
      käynnistystä, ei reaktiivisesti (aihe 8.3)
- [ ] Mitattavat ihmiset osallistuivat mittarien valintaan (aihe 8.3)
- [ ] Ohjelma alkaa pelkästään diagnostisessa tilassa, sitoutuneella
      vähimmäiskoeajalla (aihe 8.3)
- [ ] Nopea, näkyvä vastausprotokolla on olemassa mille tahansa tulevalle
      väärinkäyttötapaukselle (aihe 8.3)
- [ ] Pilottitiimi on valittu siten, että se on aidosti vapaaehtoinen, ei
      määrätty (aihe 8.5)
- [ ] Perustava hallinta (peruskirja, omistajuus, diagnostinen linjaus) on
      paikallaan ennen kuin instrumentointi alkaa (aiheet 1.4, 8.5)

## Häiriön ja jälkikatselmuksen tarkistuslista

- [ ] Jälkikatselmus tutkii järjestelmää, ei yksilöä (aihe 6.2)
- [ ] Vakavuus on luokiteltu dokumentoitujen, standardoitujen kriteerien
      mukaan (aihe 6.2)
- [ ] Havaitsemis-, kuittaus- ja ratkaisuajat on kirjattu erikseen
      (aihe 6.2)
- [ ] Toimenpiteet ovat täsmällisiä, osoitettuja ja niitä seurataan
      päätökseen asti (aihe 6.2)
- [ ] Jälkikatselmus jaetaan ilman pelkoa yksilöön kohdistuvista
      seurauksista (aiheet 6.2, 8.3)

## Tekoälyajan mittariauditoinnin tarkistuslista

- [ ] Jokainen mittariston mittari on testattu kysymyksellä: "näyttäisikö
      tekoälyavustusta paljon käyttävä tiimi, joka ei tuota todellista arvoa
      enempää, parantunutta lukemaa tässä" (aihe 7.1)
- [ ] Muutosten epäonnistumisprosentti ja virheosuus katselmoidaan
      tekoälyavusteisen julkaisutiheyden tai commit-määrän kasvun rinnalla
      (aihe 7.1)
- [ ] Katselmointikapasiteettia ja -syvyyttä seurataan tekoälyn tuottaman
      koodin määrän muuttuessa (aihe 7.1)
- [ ] Karanneet virheet merkitään tekoälyavustuksen tason mukaan sen
      testaamiseksi, ei olettamiseksi, pätevätkö historialliset
      virheosuussuhteet edelleen (aiheet 7.1, 7.3)
- [ ] "Näyttää oikealta" -virheitä kestävät havaitsemismenetelmät
      (mutaatiotestaus, ominaisuuspohjainen testaus) ovat käytössä
      tekoälyvaltaisilla koodipoluilla (aihe 7.3)
- [ ] Mittarien peruskirja on nimenomaisesti käyty uudelleen läpi ja
      päivitetty tätä muutosta varten, ei jätetty ajautumaan
      tarkastelematta (aiheet 1.4, 7.1)

## Mittariohjelman auditoinnin tarkistuslista (vuosittainen)

- [ ] Jokaisella mittarilla on yhä nimetty omistaja (aihe 1.4)
- [ ] Vähintään yksi mittari on poistettu viime kierroksella, jos se lakkasi
      ansaitsemasta paikkaansa (aihe 1.1)
- [ ] Viiden ulottuvuuden kypsyysarviointi on tehty rehellisesti,
      pisteytettynä minimillä, ei keskiarvolla (aihe 8.4)
- [ ] Yksikään mittari ei ole ajautunut diagnostisesta arvioivaan käyttöön
      ilman nimenomaista, ilmoitettua päätöstä (aihe 1.1)
- [ ] Määritelmät on pistokokein tarkistettu todellista instrumentointia
      vasten ajautumisen varalta (aiheet 1.2, 2.4, 5.1, 6.2, 6.4)
- [ ] Tulosten ja tuotosten suhde ensisijaisissa mittaristoissa on laskettu
      ja katselmoitu (aihe 7.4)
