# 9.2 הגדרות מדדים ומדריך נוסחאות

כל נוסחה מהספר, מרוכזת במקום אחד. כל ערך מציין את הנושא שבו הדיון המלא, כולל סיכון העיוות ומעקה הבטיחות שלו. השתמשו בזה כחיפוש מהיר, לא כתחליף לנושא עצמו.

## מדדי זרימה (חלק 2)

| מדד | נוסחה | נושא |
| --- | --- | --- |
| מהירות זרימה | מספר פריטי הזרימה שהושלמו ליחידת זמן | 2.3 |
| התפלגות זרימה | (פריטים שהושלמו מסוג פריט זרימה אחד) / (סך הפריטים שהושלמו) x 100% | 2.3 |
| זמן זרימה | הזמן מכניסת פריט זרימה לזרם הערך ועד מסירתו | 2.4 |
| עומס זרימה | מספר פריטי הזרימה שפעילים או ממתינים כרגע בזרם הערך | 2.4 |
| חוק ליטל | עומס זרימה (עבודה בתהליך) = קצב הגעה x זמן זרימה (זמן מחזור) | 2.4, 2.7 |
| יעילות זרימה | זמן עבודה פעילה / סך הזמן שחלף x 100% | 2.5 |
| זמן מחזור | סכום משכי השלבים: קידוד + איסוף + סקירה + בדיקה + פריסה | 2.6 |
| ניצולת | קצב הגעה / קצב שירות | 2.7 |
| אחוז שלם ונכון (%C/A) | (יחידות שמיש במורד הזרם בלי עבודה חוזרת) / (סך היחידות) x 100% | 2.8 |
| תפוקה מצטברת תקינה | %C/A של שלב 1 x %C/A של שלב 2 x ... x %C/A של שלב N | 2.8 |
| זמן טאקט | זמן עבודה זמין / ביקוש הלקוחות באותה תקופה | 2.8 |
| זמן לסקירה ראשונה | הזמן מפתיחת בקשת המשיכה ועד התגובה המהותית הראשונה של סוקר | 2.9 |
| תדירות פריסה | מספר הפריסות המוצלחות לייצור ליחידת זמן | 2.10 |
| זמן אספקה לשינויים | הזמן מהקומיט הראשון ועד פריסה מוצלחת לייצור (דווחו חציון ואחוזון 90) | 2.10 |
| שיעור כשל שינויים | (פריסות שגרמו לכשל) / (סך הפריסות) x 100% | 2.10 |
| זמן התאוששות מפריסה כושלת | הזמן מזיהוי הכשל ועד השבת שירות אמיתית | 2.10 |

## הערות על השימוש בנוסחאות האלה

- **תמיד זווגו נוסחת מהירות או תוצר עם מעקה הבטיחות שלה** (נושא 1.2): שיעור כשל שינויים עם תדירות פריסה וזמן אספקה; שיעור פגמים שנמלטו עם מהירות אספקה; צריכת תקציב שגיאות עם פעילות פריסה.
- **השתמשו בחציונים ובאחוזונים, לא בממוצעים, לנוסחאות מבוססות זמן** (נושא 1.6) אלא אם נוסחה דורשת במפורש ממוצע.
- **כל נוסחה צריכה מערכת מקור מתועדת ושיטת איסוף** (נושא 1.5) לצד ההגדרה המתמטית שלה; שני צוותים שמחשבים את אותה נוסחה ממקורות שונים לא יפיקו מספרים ברי השוואה.
- **שקלול חומרה אינו מוצג במפורש בכל נוסחה לעיל** אך חל בכל מקום שמופיע "משוקלל חומרה"; ראו את הנושא הרלוונטי למערך הסיווג המלא.
