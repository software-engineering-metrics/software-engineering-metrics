# 9.4 תבניות

תבניות להעתקה ולהדבקה למסמכים חוזרים. דוגמאות ממולאות ומפורטות של שתי הראשונות נמצאות ב-[`docs/examples/`](../examples/index.md).

## תבנית אמנת מדדים

```markdown
# אמנת מדדים: [שם הצוות או קבוצת המדדים]

- **צוות:** [הצוות הבעלים]
- **בעלים:** [אדם או תפקיד בשם]
- **נסקר:** [קצב, למשל אחת לרבעון]

## מטרה

[משפט או שניים: מה האמנה הזו מנהלת ולמה.]

## מה אנחנו עוקבים אחריו

| מדד | מקור אמת | בעלים |
| --- | --- | --- |
| [מדד] | [מערכת] | [בעלים בשם] |

## אי-מטרות

[הצהרה מפורשת על מה שהמדדים האלה אינם משמשים לו, למשל הערכת
ביצועים אישית, דירוג בין צוותים בלי הקשר.]

## מעקות בטיחות

[לכל מדד עם תמריץ, ציינו את מעקה הבטיחות המזווג לו ואיזה דפוס עיוות
הוא תופס.]

## קצב סקירה

[מתי ואיך האמנה הזו נבחנת מחדש; מה מפעיל הוצאת מדד משימוש.]
```

## תבנית מפרט לוח מחוונים

```markdown
# מפרט לוח מחוונים: [שם לוח המחוונים]

## קהל

[למי לוח המחוונים הזה מיועד, ואיזו החלטה הוא מיידע. ציינו
במפורש אם הוא אינו מיועד להערכה אישית.]

## אריחים (לפי סדר התצוגה)

1. **[שם המדד]**, [חלון זמן], [סוג תרשים]. [הערות הצגה
   ספציפיות: כללי צירים, הערות.]
2. ...

## כללי הצגה חזותית

- צירים מתחילים באפס אלא אם צוין אחרת, כשהחריגה מתועדת
  באריח.
- [כל כלל כנות אחר ייחודי לפרויקט.]

## קצב רענון

[באיזו תדירות כל אריח מתעדכן, ומאיזה מקור.]

## מה לוח המחוונים הזה מוציא החוצה במכוון

[ציינו כל דבר שהושאר בחוץ במכוון, ולמה, למשל ספירות פעילות
אישיות.]
```

## תבנית סדר יום לישיבת סקירת מדדים

```markdown
# סקירת מדדים: [תאריך]

## משתתפים

[שמות ותפקידים]

## מדדים שנסקרו

לכל מדד:
- הקריאה הנוכחית והמגמה
- כל תנועה מחוץ לשונות התקינה (נושא 1.6)
- מצב מעקה הבטיחות המזווג, אם רלוונטי
- ההחלטה שהקריאה הזו מיידעת, אם יש

## מדדים חדשים שהוצעו

[העבירו כל אחד דרך רשימת התיוג לסקירת מדד חדש, נושא 9.3.]

## מדדים שנשקלו להוצאה משימוש

[אילו מדדים לא מיידעו החלטה בשני המחזורים האחרונים?]

## פריטי פעולה

| פריט | בעלים | מועד |
| --- | --- | --- |
| | | |
```

## תבנית תחקיר ללא האשמה

```markdown
# תחקיר: [שם האירוע], [תאריך]

## תקציר

[פסקה אחת: מה קרה, השפעה על משתמשים, משך.]

## ציר זמן

- זיהוי: [שעה, איך זוהה]
- אישור קבלה: [שעה, מי הגיב]
- פתרון: [שעה, מה תיקן]

## חומרה

[סיווג מול קריטריונים מתועדים, נושא 6.2.]

## שורש הבעיה

[מה אפשר לזה לקרות, מנוסח כשאלה על המערכת, לא על
הפרט.]

## מה עבד היטב

[דברים ספציפיים שעבדו בתגובה.]

## פריטי פעולה

| פריט | בעלים | מועד |
| --- | --- | --- |
| | | |

## מעקב

[אישור שפריטי הפעולה נעקבו עד להשלמה, במחזור הסקירה
הבא.]
```

## תבנית הצדקת ROI

```markdown
# הצדקת ROI: [שם היוזמה]

## עלות (עלות כוללת לבעלות, נושא 5.5)

- ראשונית: [עלות פיתוח]
- מתמשכת: [תחזוקה, תשתית, תמיכה, לשנה]
- עלות הזדמנות: [מה עוד הקיבולת הזו הייתה יכולה לעשות]

## תועלת (ראיות מתועדות, נושאים 5.1-5.3)

- [תועלת 1], מעוגנת ב-[מקור נתונים]
- [תועלת 2], מעוגנת ב-[מקור נתונים]

## טווח והנחות

- תרחיש שמרני: [נתון]
- תרחיש אופטימי: [נתון]
- ההנחה המרכזית שמניעה את הטווח: [תנו לה שם]

## משתני בלבול שנשקלו ונשללו

[מה עוד יכול להסביר את התועלת החזויה, ולמה נשלל או נלקח
בחשבון.]

## בדיקה לאחר ההשלמה (מלאו אחרי שהיוזמה הושלמה)

- תוצאה בפועל: [נתון]
- בהשוואה לטווח החזוי: [מעל / בתוך / מתחת]
- מה זה מלמד אותנו להערכה הבאה: [הערה]
```
