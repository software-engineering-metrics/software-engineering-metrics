# בדיקות: חבילת האימות

## הרצה

```sh
just test
# or
python3 tests/validate.py
```

היא רצה מכל מקום ודורשת רק Python 3 (בלי חבילות צד שלישי, בלי רשת). היא מדפיסה שורה אחת לכל בדיקה ויוצאת בקוד שאינו אפס אם בדיקה כלשהי נכשלת, ולכן היא מתאימה ל-CI ולהוקים של pre-commit.

## מה היא בודקת

- **מספר הנושאים הצפוי** (הקבוע בראש הסקריפט).
- **מספור רציף** בכל חלק, החל מ-N.0.
- **H1 תואם את המספר העשרוני בשם הקובץ** בכל נושא.
- **כותרות H1 תואמות את `spec/structure.md`** תו אחר תו, לא רק את המספר העשרוני בתחילה.
- **סעיפים נדרשים** קיימים בכל נושא תוכן (חלקים 1 עד 8, נושא N.1 ומעלה), **בסדר התבנית המדויק**.
- **מינימום מילים** לכל נושא תוכן (1,500 מילים), עם רשימת חריגים בסקריפט לחריגים מכוונים.
- **אין מקפים ארוכים** באף קובץ Markdown.
- **מקף בינוני רק בין ספרות**, כך ש"2.1–2.8" עובר וכל השאר נכשל.
- **אין ניסוחים אסורים** ("not only", "but also", "load-bearing").
- **כל קישורי `.md` הפנימיים נפתרים.**
- **הפניות צולבות בפרוזה מצביעות על נושאים אמיתיים**: הפניה למספר נושא בלי קובץ מתאים בדיסק נכשלת, באותה תבנית הפניה שבה משתמש הקישור האוטומטי של האתר.
- **קישורי ויקיפדיה תקינים בצורתם** (`https://en.wikipedia.org/wiki/...`).
- **`spec/structure.md` תואם את הקבצים בדיסק**, בשני הכיוונים.
- **README, דף הבית ודף התוכן מקשרים לכל נושא.**

## כשבדיקה נכשלת

השורה שנכשלה מציינת את הקובץ ואת הבעיה. תיקונים נפוצים:

- נמצא מקף ארוך: נסחו מחדש את המשפט כדי להסיר את ה-"—". אל תמחקו אותו סתם.
- חסר סעיף: הוסיפו את סעיף ה-`##` החסר מתבנית הנושא.
- אי-התאמה למבנה: הוספתם או שניתם שם של נושא בלי לעדכן את `spec/structure.md`, או להפך. החזירו אותם להתאמה.
- קישור שבור: תקנו את הנתיב, או עדכנו אותו אחרי שינוי שם.
- פער במספור: מספרו מחדש כך שהחלק רציף מ-N.0.

## מעבר לחבילת האימות

- `just spell` מריץ את [codespell](https://github.com/codespell-project/codespell) על המאגר. ההגדרה, כולל רשימת התעלמות מחיוביים כוזבים, נמצאת בסעיף `[tool.codespell]` ב-`pyproject.toml`.
- `just stats` מדפיס דוח Markdown (ספירת מילים לנושא, נושאים דלים, קישורי ויקיפדיה, ערכי מקורות) מ-`tools/stats.py`.

## אינטגרציה רציפה

- `.github/workflows/test.yml` רץ בכל בקשת משיכה ובדחיפות לענפים שאינם main: חבילת האימות ו-codespell. המאגר הזה לא בונה ולא פורס אתר; ההצגה מתרחשת במאגר הנפרד `software-engineering-metrics.github.io`.
- `.github/workflows/links.yml` בודק קישורים חיצוניים אחת לשבוע בעזרת [lychee](https://github.com/lycheeverse/lychee) (תבניות התעלמות ב-`.lycheeignore`) ושומר את התוצאות ב-issue יחיד בשם "Link checker report". קישורים חיצוניים נשארים מחוץ למסלול בקשות המשיכה בכוונה.

## מה הבדיקות לא מכסות

החבילה בודקת מבנה וסגנון, לא אמת. היא לא יכולה לדעת אם מקור אמיתי או אם הפרוזה מדויקת. אמתו ציטוטים ועובדות ביד או בסבב מחקר. גם קיום קישורי ויקיפדיה (בניגוד לצורתם) דורש בדיקה ברשת, שהחבילה משאירה בכוונה בחוץ כדי שתוכל לרוץ בלי רשת.
