# דוגמאות

דוגמאות קטנות וקונקרטיות שמראות את רעיונות הספר בשימוש. הן להמחשה ולא ממצות. התבניות המלאות נמצאות בנספחים ([נושא 9.4, תבניות](../chapters/09-04-תבניות.md)).

## תוכן

- **[דוגמה-לאמנת-מדדים.md](metrics-charter-example.md)** : אמנת מדדים מלאה, מהסוג שמתואר ב[נושא 1.4](../chapters/01-04-ממשל-מדדים-ואחריות.md).
- **[דוגמה-למפרט-לוח-מחוונים.md](dashboard-spec-example.md)** : מפרט מפורט של לוח מחוונים למדדי אספקה, בהתאם ל[נושא 8.1](../chapters/08-01-תכנון-לוח-מחוונים-למדדי-הנדסה.md).
- **שלד נושא** : כדי להתחיל נושא חדש, העתיקו את [תבנית הנושא](../contributing/chapter-template.md).

## איך להשתמש בהן

מעתיקים דוגמה, מחליפים את התוכן בתוכן שלכם ושומרים על הצורה. מה שחשוב הוא המבנה ורמת הפירוט, לא הערכים הספציפיים.
