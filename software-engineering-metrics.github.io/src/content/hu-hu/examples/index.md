# Példák

Kicsi, konkrét példák, amelyek a könyv gondolatait mutatják használat közben. Szemléltető jellegűek, nem kimerítőek. A teljes sablonok a függelékekben vannak ([9.4 téma, Sablonok](../chapters/09-04-sablonok.md)).

## Tartalom

- **[pelda-metrikacharta.md](metrics-charter-example.md)** : kitöltött metrikacharta, amilyet az [1.4 téma](../chapters/01-04-metrikagovernance-es-felelosseg.md) ír le.
- **[pelda-dashboard-specifikacio.md](dashboard-spec-example.md)** : kidolgozott dashboard-specifikáció egy szállítási metrikákat mutató dashboardhoz, a [8.1 téma](../chapters/08-01-mernoki-metrikak-dashboardjanak-tervezese.md) nyomán.
- **Témavázlat** : új téma indításához másold le a [témasablont](../contributing/chapter-template.md).

## Használatuk

Másolj le egy példát, cseréld a tartalmat a sajátodra, és tartsd meg az alakját. A lényeg a szerkezet és a részletesség szintje, nem a konkrét értékek.
