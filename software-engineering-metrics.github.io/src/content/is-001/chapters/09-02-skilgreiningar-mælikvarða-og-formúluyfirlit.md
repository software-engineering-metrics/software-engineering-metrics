# 9.2 Skilgreiningar mælikvarða og formúluyfirlit

Sérhver formúla úr bókinni, safnað á einn stað. Hver færsla nefnir viðfangsefnið þar sem full umfjöllun er, þar með leikáhættu hennar og varnarmælikvarða. Notaðu þetta sem fljótlega uppflettingu, ekki í staðinn fyrir viðfangsefnið sjálft.

## Flæðimælikvarðar (2. hluti)

| Mælikvarði | Formúla | Viðfangsefni |
| --- | --- | --- |
| Flæðishraði | Fjöldi flæðiatriða kláraður á tímaeiningu | 2.3 |
| Flæðisdreifing | (Kláruð atriði einnar gerðar flæðiatriða) / (Heildarfjöldi kláraðra atriða) x 100% | 2.3 |
| Flæðistími | Tími frá því flæðiatriði fer inn í virðisstrauminn þar til það er afhent | 2.4 |
| Flæðisálag | Fjöldi flæðiatriða sem eru nú virk eða bíða í virðisstraumnum | 2.4 |
| Lögmál Littles | Flæðisálag (vinna í vinnslu) = Komuhraði x Flæðistími (ferlitími) | 2.4, 2.7 |
| Flæðinýtni | Virkur vinnutími / Heildarlíðandi tími x 100% | 2.5 |
| Ferlitími | Summa stigalengda: kóðun + upptaka + yfirferð + prófun + afhending | 2.6 |
| Nýting | Komuhraði / Afgreiðsluhraði | 2.7 |
| Hlutfall fullbúins og nákvæms (%C/A) | (Einingar nothæfar niðurstreymis án endurvinnu) / (Heildarfjöldi eininga) x 100% | 2.8 |
| Samanlögð afkastanýting | %C/A stigs 1 x %C/A stigs 2 x ... x %C/A stigs N | 2.8 |
| Taktur-tími | Tiltækur vinnutími / Eftirspurn viðskiptavina á því tímabili | 2.8 |
| Tími til fyrstu yfirferðar | Tími frá því sameiningarbeiðni er opnuð þar til fyrsta efnisleg viðbrögð yfirferðaraðila berast | 2.9 |
| Afhendingartíðni | Fjöldi vel heppnaðra framleiðsluafhendinga á tímaeiningu | 2.10 |
| Leiðartími breytinga | Tími frá fyrstu innsendingu til vel heppnaðrar framleiðsluafhendingar (skýrðu frá miðgildi og 90. hundraðshlutamarki) | 2.10 |
| Breytingabilunarhlutfall | (Afhendingar sem valda bilun) / (Heildarfjöldi afhendinga) x 100% | 2.10 |
| Batatími misheppnaðra afhendinga | Tími frá greiningu bilunar þar til þjónusta er sannarlega endurheimt | 2.10 |

## Þróunarupplifun (3. hluti)

| Mælikvarði | Formúla | Viðfangsefni |
| --- | --- | --- |
| Einbeitingartími | Fjöldi og lengd ótruflaðra tveggja klukkustunda-plús blokka á viku, úr dagatalsgögnum | 3.6 |
| Svarhlutfall | (Könnunarsvör móttekin) / (Könnunarboð send) x 100% | 3.7 |

## Kóði og gæði (4. hluti)

| Mælikvarði | Formúla | Viðfangsefni |
| --- | --- | --- |
| Hringkomplexitet | Óháðar leiðir gegnum stýriflæði (leggir − hnútar + 2, samkvæmt McCabe) | 4.1 |
| Prófþekja | (Línur/greinar keyrðar af prófum) / (Heildarfjöldi lína/greina) x 100% | 4.2 |
| Stökkbrigðadrápshlutfall | (Stökkbrigði drepin af prófasafni) / (Heildarfjöldi innleiddra stökkbrigða) x 100% | 4.2 |
| Kóðavelta | Línur bættar við + breyttar + eyddar á skrá yfir tímaglugga | 4.3 |
| Heitreitaeinkunn | Velta x Flækjustig, raðað á skrá | 4.3 |
| Burðarkostnaður skuldar | Áætlaður áframhaldandi kostnaður við að laga atriði ekki (hægari tengd vinna, hækkuð gallaáhætta) | 4.5 |

## Vara og rekstur (5. hluti)

| Mælikvarði | Formúla | Viðfangsefni |
| --- | --- | --- |
| Hlutfall sloppinna galla | (Alvarleikavegnir sloppnir gallar) / (Afhendingar- eða tímaeining) | 5.1 |
| Upphafsupptaka | (Notendur sem prófuðu eiginleikann að minnsta kosti einu sinni) / (Markáheyrendur) x 100% | 5.2 |
| Varðveitt upptaka | (Notendur sem nota eiginleikann enn eftir N vikur) / (Notendur sem prófuðu hann upphaflega) x 100% | 5.2 |
| Einingarkostnaður | Heildarkostnaður (fólk + innviðir + tól) / Marktæk eining (viðskiptavinur, færsla) | 5.4 |
| ROI | (Heildarábati − Heildareignarkostnaður) / Heildareignarkostnaður, sett fram sem bil | 5.5 |

## Áreiðanleiki, rekstur og öryggi (6. hluti)

| Mælikvarði | Formúla | Viðfangsefni |
| --- | --- | --- |
| Villuheimild | (1 − SLO-mark) x Tímagluggi (t.d. 0,1% af 30 dögum ≈ 43 mínútur) | 6.1 |
| Brunahraði villuheimildar | Villuheimild eydd / Villuheimild úthlutuð, yfir tiltekinn glugga | 6.1 |
| MTTD | Tími frá upphafi atviks þar til það er greint | 6.2 |
| MTTA | Tími frá tilkynningu atviks þar til það er staðfest | 6.2 |
| MTTR (atvik) | Tími frá staðfestingu þar til þjónusta er sannarlega endurheimt | 6.2 |
| Boðadreifing bakvaktar | Boð móttekin á einstakling, yfir veltandi glugga (ekki teymismeðaltal) | 6.3 |
| Tími-til-úrbóta veikleika | Tími frá uppgötvun þar til sannarlegar úrbætur, rakinn eftir alvarleika | 6.4 |

## Athugasemdir um notkun þessara formúla

- **Paraðu alltaf hraða- eða afurðaformúlu við varnarmælikvarða hennar** (viðfangsefni 1.2): breytingabilunarhlutfall með afhendingartíðni og leiðartíma; hlutfall sloppinna galla með afhendingarhraða; brunahraða villuheimildar með afhendingarvirkni.
- **Notaðu miðgildi og hundraðshlutamörk, ekki meðaltöl, fyrir tímabundnar formúlur** (viðfangsefni 1.6) nema formúla kalli sérstaklega á meðaltal.
- **Sérhver formúla þarfnast skjalfests upprunakerfis og söfnunaraðferðar** (viðfangsefni 1.5) samhliða stærðfræðilegri skilgreiningu sinni; tvö teymi sem reikna sömu formúlu úr ólíkum uppsprettum munu ekki framleiða sambærilegar tölur.
- **Alvarleikavigtun er ekki sýnd skýrt í sérhverri formúlu hér að ofan** en gildir hvar sem „alvarleikavegið“ birtist; sjá viðkomandi viðfangsefni fyrir fullt flokkunarkerfi.
