# Dæmi

Lítil, áþreifanleg dæmi sem sýna hugmyndir bókarinnar í notkun. Þau eru lýsandi, ekki tæmandi. Fullu sniðmátin eru í viðaukunum ([viðfangsefni 9.4, Sniðmát](../chapters/09-04-sniðmát.md)).

## Efni

- **[dæmi-um-mælikvarðasáttmála.md](metrics-charter-example.md)** : útfylltur mælikvarðasáttmáli, sú tegund sem lýst er í [viðfangsefni 1.4](../chapters/01-04-stjórnarhættir-og-eignarhald-mælikvarða.md).
- **[dæmi-um-mælaborðsforskrift.md](dashboard-spec-example.md)** : unnin mælaborðslýsing fyrir afhendingarmælikvarðamælaborð, eftir [viðfangsefni 8.1](../chapters/08-01-að-hanna-mælaborð-verkfræðimælikvarða.md).
- **Viðfangsefnisgrind** : til að byrja nýtt viðfangsefni, afritaðu [viðfangsefnissniðmátið](../contributing/chapter-template.md).

## Að nota þetta

Afritaðu dæmi, skiptu efninu út fyrir þitt eigið og haltu lögun þess. Atriðið er byggingin og smáatriðastigið, ekki sértæku gildin.
