# Esempi

Esempi piccoli e concreti che mostrano le idee del libro in uso. Sono illustrativi, non
esaustivi. I modelli completi si trovano nelle appendici
([argomento 9.4, Modelli](../chapters/09-04-modelli.md)).

## Contenuti

- **[esempio-carta-delle-metriche-team-piattaforma-pagamenti.md](metrics-charter-example.md)** :
  una carta delle metriche compilata, del tipo descritto nell'[argomento 1.4](../chapters/01-04-governance-e-responsabilita-delle-metriche.md).
- **[esempio-specifica-dashboard-metriche-di-consegna.md](dashboard-spec-example.md)** :
  una specifica di dashboard svolta per una dashboard di metriche di consegna, secondo
  l'[argomento 8.1](../chapters/08-01-progettare-una-dashboard-di-metriche-di-ingegneria.md).
- **Scheletro di argomento** : per iniziare un nuovo argomento, copia il
  [modello di argomento](../contributing/chapter-template.md).

## Come usarli

Copia un esempio, sostituisci il contenuto con il tuo e mantieni la forma. Il punto è la
struttura e il livello di dettaglio, non i valori specifici.
