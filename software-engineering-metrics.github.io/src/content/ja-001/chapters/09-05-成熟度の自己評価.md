# 9.5 成熟度の自己評価

第1部から第8部までのすべてのトピックは、5段階の成熟度モデルで終わります:1 開始、2 発展、3 標準化、4 管理、5 最適化。この付録は、組織的な自己評価のためにそれらを一つの行列に統合します。願望ではなく具体的な証拠を使って、各トピックを正直に採点してください。このトピックごとの行列が補完する横断的な5次元のプログラムモデルについてはトピック8.4を参照してください。そして、プログラムの成熟度は次元にわたる平均ではなく最小値であることを忘れないでください。

## この行列の使い方

1. 各トピックについて、その独自の成熟度モデルを読んでください(そのトピックが権威のある情報源であり、この表は要約索引です)。
2. 意図ではなく具体的な証拠に対して、あなたの組織を1から5まで採点してください。
3. 部の中でトピックにわたって平均化しないでください。各トピックは別個の能力を測定します。
4. 低いスコアを、それについて気分が悪くなる評決としてではなく(トピック1.1)、投資の優先順位としてトピック8.5の採用のロードマップに供給してください。
