# Przykłady

Małe, konkretne przykłady pokazujące idee tej książki w użyciu. Są ilustracyjne, a nie wyczerpujące. Pełne szablony znajdziesz w załącznikach ([temat 9.4, Szablony](../chapters/09-04-szablony.md)).

## Zawartość

- **[przyklad-karty-metryk.md](metrics-charter-example.md)** : wypełniona karta metryk, taka, jaką opisuje [temat 1.4](../chapters/01-04-nadzor-i-wlasnosc-metryk.md).
- **[przyklad-specyfikacji-panelu.md](dashboard-spec-example.md)** : rozpracowana specyfikacja panelu metryk dostarczania, zgodna z [tematem 8.1](../chapters/08-01-projektowanie-panelu-metryk-inzynierskich.md).
- **Szkielet tematu** : żeby zacząć nowy temat, skopiuj [szablon tematu](../contributing/chapter-template.md).

## Jak z nich korzystać

Skopiuj przykład, zastąp treść własną i zachowaj kształt. Liczy się struktura i poziom szczegółowości, a nie konkretne wartości.
