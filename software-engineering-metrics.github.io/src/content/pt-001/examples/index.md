# Exemplos

Exemplos pequenos e concretos que mostram as ideias do livro em uso. São ilustrativos, não exaustivos. Os modelos completos estão nos apêndices
([tema 9.4, Modelos](../chapters/09-04-modelos.md)).

## Conteúdo

- **[exemplo-de-carta-de-metricas.md](metrics-charter-example.md)** : uma carta de métricas preenchida, do tipo descrito no
  [tema 1.4](../chapters/01-04-governação-e-propriedade-das-métricas.md).
- **[exemplo-de-especificacao-de-painel.md](dashboard-spec-example.md)** : uma especificação de painel concretizada para um painel de métricas de entrega, seguindo o
  [tema 8.1](../chapters/08-01-desenhar-um-painel-de-métricas-de-engenharia.md).
- **Esqueleto de tema** : para começar um tema novo, copie o [modelo de tema](../contributing/chapter-template.md).

## Usá-los

Copie um exemplo, substitua o conteúdo pelo seu e mantenha a forma. O que importa é a estrutura e o nível de detalhe, não os valores específicos.
