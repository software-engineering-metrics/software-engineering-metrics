# 9.5 Autoevaluarea maturității

Fiecare subiect din Părțile 1–8 se încheie cu un model de maturitate cu cinci
niveluri: 1 Inițiere, 2 Dezvoltare, 3 Standardizare, 4 Gestionare, 5
Orchestrare. Această anexă le consolidează într-o singură matrice pentru
autoevaluare organizațională. Notează fiecare subiect onest, pe dovezi
concrete, nu pe aspirații. Vezi subiectul 8.4 pentru modelul transversal al
programului, cu cinci dimensiuni, pe care această matrice subiect cu subiect îl
completează, și amintește-ți că maturitatea programului este minimul dintre
dimensiuni, nu media.

## Cum folosești această matrice

1. Pentru fiecare subiect, citește propriul lui model de maturitate (subiectul
   este sursa autoritară; acest tabel este un index-rezumat).
2. Notează-ți organizația de la 1 la 5, pe dovezi concrete, nu pe intenții.
3. Nu face media între subiectele aceleiași părți; fiecare subiect măsoară o
   capacitate distinctă.
4. Folosește scorurile scăzute în foaia de parcurs de adoptare din subiectul 8.5
   ca priorități de investiție, nu ca verdict de care să-ți pară rău
   (subiectul 1.1).
