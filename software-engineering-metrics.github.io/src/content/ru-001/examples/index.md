# Примеры

Небольшие конкретные примеры, показывающие идеи книги в действии. Они иллюстративны, а не исчерпывающи. Полные шаблоны находятся в приложениях
([тема 9.4, Шаблоны](../chapters/09-04-шаблоны.md)).

## Содержание

- **[пример-устава-метрик.md](metrics-charter-example.md)** : заполненный устав метрик, того вида, что описан в
  [теме 1.4](../chapters/01-04-управление-метриками-и-владение-ими.md).
- **[пример-спецификации-дашборда.md](dashboard-spec-example.md)** : проработанная спецификация дашборда для дашборда метрик поставки, по
  [теме 8.1](../chapters/08-01-проектирование-панели-инженерных-метрик.md).
- **Каркас темы** : чтобы начать новую тему, скопируйте [шаблон темы](../contributing/chapter-template.md).

## Как ими пользоваться

Скопируйте пример, замените содержимое своим и сохраните форму. Важны структура и уровень детализации, а не конкретные значения.
