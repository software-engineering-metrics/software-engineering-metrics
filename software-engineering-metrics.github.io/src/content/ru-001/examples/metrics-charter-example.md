# Пример: устав метрик для команды платёжной платформы

Проработанный пример устава метрик, одностраничного документа, описанного в
[теме 1.4, Управление метриками и владение ими](../chapters/01-04-управление-метриками-и-владение-ими.md). Важна форма: заявленная цель,
явные не-цели, названные владельцы и каденция пересмотра. Устав такого размера предназначен для чтения, а не для того, чтобы лежать в архиве.

- **Команда:** Платёжная платформа
- **Владелец:** Инженерный менеджер платформы
- **Пересматривается:** Ежеквартально, на ревью платформы

## Цель

Этот устав регулирует метрики, которые команда платёжной платформы отслеживает по собственной поставке и надёжности. Он существует для того, чтобы каждый, внутри команды и вне её,
мог увидеть, что измеряется, почему и для чего не используется.

## Что мы отслеживаем

| Метрика | Источник истины | Владелец |
| --- | --- | --- |
| Частота развёртываний | Конвейер CI/CD | Лид платформы |
| Время выполнения изменений | Git плюс конвейер развёртывания | Лид платформы |
| Доля неудачных изменений | Трекер инцидентов, с тегом на каждое развёртывание | Лид дежурств |
| Время восстановления после неудачного развёртывания | Трекер инцидентов | Лид дежурств |
| Задержка API P99 (SLI) | Платформа наблюдаемости | Лид SRE |
| Расход бюджета ошибок | Платформа наблюдаемости | Лид SRE |

## Не-цели

Эти метрики никогда, по отдельности или вместе, не используются для ранжирования инженеров, суждения об оценках результативности или сравнения этой команды с дорожной картой другой команды
без сравнения также объёма работ, штата и зрелости системы. Любое использование за пределами заявленной выше цели требует одобрения директора по инженерии
и самой команды.

## Страховочные метрики

Каждая метрика выше, несущая стимул, сочетается со страховочной метрикой. Время выполнения изменений отслеживается вместе с долей неудачных изменений, чтобы команда
не могла улучшить показатель скорости, выпуская более рискованные изменения. Частота развёртываний по той же причине отслеживается вместе с расходом бюджета ошибок.

## Каденция пересмотра

Команда пересматривает этот устав ежеквартально. Метрика, не изменившая ни одного решения два квартала подряд, кандидат на выход на покой.
