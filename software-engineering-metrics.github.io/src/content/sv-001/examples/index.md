# Exempel

Små, konkreta exempel som visar bokens idéer i bruk. De är illustrativa, inte uttömmande. De fullständiga mallarna finns i bilagorna
([ämne 9.4, Mallar](../chapters/09-04-mallar.md)).

## Innehåll

- **[exempel-på-metrikstadga.md](metrics-charter-example.md)** : en ifylld metrikstadga, av den typ som beskrivs i
  [ämne 1.4](../chapters/01-04-styrning-och-ägarskap-av-metriker.md).
- **[exempel-på-specifikation-för-instrumentpanel.md](dashboard-spec-example.md)** : en utarbetad specifikation för en instrumentpanel med leveransmätetal, enligt
  [ämne 8.1](../chapters/08-01-att-designa-en-ingenjörsmätetalsinstrumentpanel.md).
- **Ämnesskelett** : för att påbörja ett nytt ämne, kopiera [ämnesmallen](../contributing/chapter-template.md).

## Använda dem

Kopiera ett exempel, byt ut innehållet mot ditt eget och behåll formen. Poängen är strukturen och detaljnivån, inte de specifika värdena.
