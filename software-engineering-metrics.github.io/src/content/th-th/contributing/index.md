# การมีส่วนร่วม

ขอบคุณที่ช่วยปรับปรุงหนังสือเล่มนี้ ยินดีต้อนรับการมีส่วนร่วมทุกขนาด
ตั้งแต่แก้คำผิดไปจนถึงเขียนหัวข้อใหม่

## กติกาพื้นฐาน

หนังสือเล่มนี้ยึดสไตล์การเขียนที่เข้มงวด ประเด็นสำคัญคือ:

- ห้ามใช้เส้นประยาว (em-dash) ให้ใช้เครื่องหมายจุลภาค มหัพภาคคู่ วงเล็บ หรือแยกเป็นสองประโยคแทน
- ห้ามใช้สำนวนสำเร็จรูป ("not only ... but also", "load-bearing" และทำนองเดียวกัน)
- เขียนอย่างอบอุ่น เรียบง่าย ตรงไปตรงมา เรียกผู้อ่านว่า "คุณ" ใช้ประโยคสั้น
- นิยามศัพท์เมื่อใช้ครั้งแรก และลิงก์แนวคิดสำคัญไปยัง Wikipedia เมื่อกล่าวถึงครั้งแรก
- อ้างอิงเฉพาะของจริง
- หัวข้อตระกูลตัวชี้วัดทุกหัวข้อต้องระบุ gaming vector และ guardrail ของมัน

กฎฉบับเต็มอยู่ใน `spec/conventions.md` ที่ราก repository และฉบับย่อคือ[กฎสไตล์](style-rules.md)
ส่วนที่เป็นกลไกถูกบังคับด้วยการทดสอบ

## การตั้งค่า

คุณต้องมี Python 3 และ [just](https://github.com/casey/just) repository นี้เก็บเนื้อหาของหนังสือและข้อกำหนด
รวมถึงเว็บไซต์ SvelteKit (`software-engineering-metrics.github.io/`) ที่แปลงเนื้อหาเป็นเว็บไซต์ที่เผยแพร่

```sh
just         # list tasks
just test    # run the validation suite
just nav     # regenerate the generated navigation files
just stats   # topic and word counts
```

## การเปลี่ยนแปลง

1. อ่านคู่มือที่เกี่ยวข้อง: [การเขียนและแก้ไข](authoring.md)สำหรับหัวข้อ
   [การนำทาง](navigation.md)สำหรับไฟล์ที่สร้างอัตโนมัติ และ[การทดสอบ](testing.md)สำหรับชุดทดสอบ
2. ทำการเปลี่ยนแปลงที่เล็กที่สุดที่ทำงานได้
3. หากคุณเพิ่ม ลบ เปลี่ยนชื่อ หรือเปลี่ยนเลขหัวข้อ ให้อัปเดต
   `spec/structure.md` ที่ราก repository แล้วรัน `just nav`
4. รัน `just test` ต้องผ่าน
5. เพิ่มบรรทัดเดียวใน[บันทึกการเปลี่ยนแปลง](../project/changelog.md)ใต้ **Unreleased**

## อะไรที่ช่วยได้

- แก้ข้อผิดพลาด ข้อความที่ไม่ชัดเจน หรือการอ้างอิงที่ล้าสมัย
- ปรับปรุงตัวอย่าง โดยเฉพาะตัวอย่างระดับองค์กรขนาดใหญ่และหน่วยงานรัฐที่เป็นรูปธรรม
- ตรวจสอบการอ้างอิงเทียบกับแหล่งจริง
- เติมช่องว่างในการครอบคลุมของหัวข้อ โดยไม่ทำลายเทมเพลต

## สิ่งที่ควรหลีกเลี่ยง

- อย่าแก้ไฟล์ที่สร้างอัตโนมัติด้วยมือ (`README.md`, `index.md` ของแต่ละ locale,
  `front-matter/table-of-contents.md` และ
  `topics/09-07-index.md`) ให้แก้หัวข้อแล้วรัน `just nav` แทน
- อย่าแก้ `en-001`, `en-gb` หรือ `en-us` โดยตรง เพราะสร้างจาก
  `en-gb-oxendict` ด้วย `tools/localize.py`
- อย่าเพิ่มหัวข้อโดยไม่อัปเดต `spec/structure.md` ด้วย
- อย่าใส่เส้นประยาวหรือวลีต้องห้าม เพราะการทดสอบจะไม่ผ่าน

## การรายงานปัญหา

เปิด issue โดยอธิบายปัญหา ไฟล์และหัวข้อ และหากเกี่ยวข้อง ให้ระบุแหล่งหรือเอกสารอ้างอิงที่ถูกต้อง
รายงานที่สั้นและเฉพาะเจาะจงดำเนินการได้ง่ายที่สุด
