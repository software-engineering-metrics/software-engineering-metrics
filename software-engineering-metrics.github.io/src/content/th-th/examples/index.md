# ตัวอย่าง

ตัวอย่างสั้น ๆ ที่เป็นรูปธรรมซึ่งแสดงแนวคิดของหนังสือเมื่อนำไปใช้จริง ตัวอย่างเหล่านี้
มีไว้อธิบาย ไม่ได้ครอบคลุมทั้งหมด เทมเพลตฉบับเต็มอยู่ในภาคผนวก
([หัวข้อ 9.4 เทมเพลต](../chapters/09-04-แม่แบบ.md))

## เนื้อหา

- **[กฎบัตรตัวชี้วัดตัวอย่าง.md](metrics-charter-example.md)** : กฎบัตรตัวชี้วัด
  ที่กรอกแล้ว ซึ่งเป็นชนิดเดียวกับที่อธิบายใน
  [หัวข้อ 1.4](../chapters/01-04-การกำกับดูแลและความเป็นเจ้าของตัวชี้วัด.md)
- **[ตัวอย่างข้อกำหนดแดชบอร์ด.md](dashboard-spec-example.md)** : ข้อกำหนด
  แดชบอร์ดที่ลงรายละเอียดสำหรับแดชบอร์ดตัวชี้วัดการส่งมอบ ตามแนวทางของ
  [หัวข้อ 8.1](../chapters/08-01-การออกแบบแดชบอร์ดตัวชี้วัดวิศวกรรม.md)
- **โครงร่างหัวข้อ** : หากจะเริ่มหัวข้อใหม่ ให้คัดลอก
  [เทมเพลตหัวข้อ](../contributing/chapter-template.md)

## วิธีใช้

คัดลอกตัวอย่าง แทนที่เนื้อหาด้วยของคุณเอง และคงรูปทรงไว้ จุดสำคัญคือโครงสร้างและระดับของรายละเอียด
ไม่ใช่ค่าเฉพาะเจาะจง
