# Співпраця

Дякуємо, що допомагаєте покращувати цю книгу. Вітається внесок будь-якого
розміру: від виправлення описки до написання нової теми.

## Основні правила

Книга дотримується суворого стилю. Головне:

- Жодних довгих тире. Використовуйте кому, двокрапку, дужки або два речення.
- Жодних шаблонних зворотів («не лише ... а й», «load-bearing» тощо).
- Тепле, просте, пряме письмо. Звертайтеся до читача на «ви». Короткі речення.
- Визначайте терміни при першому вжитку. Посилайтеся на Wikipedia при першій
  згадці ключових понять.
- Лише справжні джерела.
- Кожна тема про родину метрик називає свій вектор маніпулювання і запобіжник.

Повні правила містяться в `spec/conventions.md` у корені репозиторію, а коротка
версія це [правила стилю](style-rules.md). Механічну частину вимог
перевіряють тести.

## Налаштування

Вам потрібні Python 3 і [just](https://github.com/casey/just). Цей репозиторій
містить вміст книги та її специфікацію, а також сайт на SvelteKit
(`software-engineering-metrics.github.io/`), що відображає її як опублікований
вебсайт.

```sh
just         # list tasks
just test    # run the validation suite
just nav     # regenerate the generated navigation files
just stats   # topic and word counts
```

## Як внести зміну

1. Прочитайте відповідний посібник: [написання тем](authoring.md) для тем,
   [навігація](navigation.md) для згенерованих файлів, [тестування](testing.md)
   для тестів.
2. Робіть найменшу зміну, яка виконує завдання.
3. Якщо ви додали, видалили, перейменували чи перенумерували тему, оновіть
   `spec/structure.md` у корені репозиторію й запустіть `just nav`.
4. Запустіть `just test`. Він має пройти.
5. Додайте однорядковий запис до [журналу змін](../project/changelog.md) під
   **Unreleased**.

## Над чим працювати

- Виправляйте помилки, неясні місця чи застарілі посилання.
- Покращуйте приклади, особливо конкретні приклади для великих компаній і
  державного сектору.
- Перевіряйте цитати за справжніми джерелами.
- Заповнюйте прогалини в охопленні теми, не порушуючи шаблон.

## Чого уникати

- Не редагуйте згенеровані файли вручну (`README.md`, `index.md` кожної локалі,
  `front-matter/table-of-contents.md` і `topics/09-07-index.md`). Змініть теми й
  запустіть `just nav`.
- Не редагуйте `en-001`, `en-gb` чи `en-us` напряму: вони виводяться з
  `en-gb-oxendict` інструментом `tools/localize.py`.
- Не додавайте тему без оновлення `spec/structure.md`.
- Не вживайте довгих тире й заборонених зворотів: тести впадуть.

## Повідомлення про проблеми

Відкрийте issue з описом проблеми, файлу й теми та, де доречно, правильного
джерела чи посилання. Невеликі, конкретні повідомлення найлегше опрацювати.
