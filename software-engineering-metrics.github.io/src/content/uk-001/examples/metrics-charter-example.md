# Приклад: хартія метрик для команди платіжної платформи

Розібраний приклад хартії метрик, односторінкового документа, описаного в
[темі 1.4, Управління метриками та відповідальність за них](../chapters/01-04-управління-метриками-та-відповідальність.md).
Важлива форма: сформульована мета, явна не-мета, названі власники й
періодичність перегляду. Така коротка хартія призначена для читання, а не для
архіву.

- **Команда:** платіжна платформа
- **Власник:** менеджер платформної інженерії
- **Перегляд:** щокварталу, на платформному огляді

## Мета

Ця хартія регулює метрики, які команда платіжної платформи відстежує щодо
власного постачання та надійності. Вона існує, щоб кожен, і в команді, і поза
нею, бачив, що вимірюється, навіщо й для чого це не призначено.

## Що ми відстежуємо

| Метрика | Першоджерело істини | Власник |
| --- | --- | --- |
| Частота розгортань | Конвеєр CI/CD | Керівник платформи |
| Час виконання змін | Git і конвеєр розгортання | Керівник платформи |
| Частка невдалих змін | Трекер інцидентів, позначений за розгортанням | Керівник чергувань |
| Час відновлення після невдалого розгортання | Трекер інцидентів | Керівник чергувань |
| Затримка API за P99 (SLI) | Платформа спостережуваності | Керівник SRE |
| Витрата бюджету помилок | Платформа спостережуваності | Керівник SRE |

## Не-цілі

Ці метрики ніколи, окремо чи в комбінації, не використовують, щоб ранжувати
інженерів, оцінювати їх у performance review або порівнювати цю команду з
дорожньою картою іншої без порівняння також обсягу, штату та зрілості системи.
Будь-яке використання поза описаною метою потребує погодження директора з
інженерії та самої команди.

## Запобіжники

Кожна метрика вище, що несе стимул, поєднана із запобіжником. Час виконання
змін розглядають разом із часткою невдалих змін, тож команда не може
поліпшити показник швидкості, випускаючи ризикованіші зміни. Частоту
розгортань розглядають разом із витратою бюджету помилок, з тієї самої причини.

## Періодичність перегляду

Команда переглядає цю хартію щокварталу. Метрика, що не змінила жодного
рішення два квартали поспіль, є кандидатом на вилучення.
