# 8.0 第8部分导言：建立一套指标项目

本书前面的每一部分都深入涵盖了一个指标家族：该衡量什么，它是如何被操纵的，以及什么护栏能捕捉到这种操纵。这最后一个实质性部分，从"该衡量什么"转向"该如何构建并运行"把这一切付诸实践的组织性项目。一个读完了本书每个主题、却从未构建过仪表盘、工具决策、推行计划，以及本部分所涵盖的成熟度路线图的组织，拥有出色的知识，却没有一套真正运作的指标项目。这一部分的存在，正是为了弥合这个缺口。

这里的五个主题遵循真正从零开始建立一套指标项目、或修复一套已经偏离本书原则的项目的自然顺序。主题 8.1 专门涵盖仪表盘设计，把第1部分到第7部分中的诸多指标，转化成一套连贯、诚实、可用的视图。主题 8.2 涵盖每个组织最终都会为其指标工具面对的自建与购买决策。主题 8.3 是本书最以人为本的一个主题，直接应对一次指标推行可能激起的恐惧，以及如何防止这种恐惧腐蚀这个项目所依赖的数据本身，呼应了本书自始至终对主题 1.2 的警告。主题 8.4 把每个主题各自的五级成熟度模型，整合成一个单一、连贯的组织自我评估框架。主题 8.5 以一份具体、按顺序排列的采用路线图，为本书的实质性内容收尾。

对大团队而言，这一部分正是本书的理念要么变成持久的组织实践、要么依然只是一份没有人真正实施的、在智识上令人满足的文档的分水岭。规模庞大、真正面临半吊子措施可能比完全没有指标项目产生更糟结果这一风险（主题 8.3 的核心警告）的企业和政府组织，依赖这一部分的实用指导，把本书的原则转化成一次真正有效的推行，而不是一次激起恐惧、产生被操纵的数据、并印证每一位怀疑者对指标项目会给团队带来什么最糟糕假设的推行。

## 本部分各主题

- **8.1 设计一套工程指标仪表盘：** 把本书的诸多指标，转化成一套面向不同受众、连贯、诚实、可操作的视图。
- **8.2 工具生态：自建与购买：** 选择或构建指标工具时真实存在的权衡取舍，以及如何做决定。
- **8.3 推行指标而不滋生恐惧：** 本部分实用性最重要的单一主题，讲的是如何防止一套指标项目激起恰恰是本书自始至终所警告的那种操纵行为。
- **8.4 工程指标项目的成熟度模型：** 一个整合的、五级的成熟度框架，把每个主题各自的模型汇聚在一起。
- **8.5 一份增量式采用路线图：** 一条具体的、分阶段的、按顺序排列的路径，从你的组织当前所处的任何位置，通向一套成熟的指标项目。

## 这些主题如何相互关联

主题 8.1 正是第1部分到第7部分中那些抽象的指标家族，变成一个真实人们真正会去看的具体产出物，也就是仪表盘的地方。主题 8.2 涵盖了那个仪表盘所依赖的工具决策。主题 8.3 是这一部分的枢纽主题：它应对的是决定本书所建议的一切究竟是真正产生可信数据、还是被恐惧悄悄腐蚀的人性和组织动力学，直接呼应了开启整本书的主题 1.2 古德哈特定律警告。主题 8.4 整合了前面每个主题各自已经提供过的评估框架，主题 8.5 把这个整合后的评估，转化成一份真正的、按顺序排列的计划。

这一部分也正是本书的附录（第9部分）变得最直接有用的地方：本书所提供的模板（主题 9.4）和清单（主题 9.3），正是专门为支持这一部分所描述的推行工作而构建的，而整合后的成熟度自我评估（主题 9.5）正是主题 8.4 框架的直接伴侣。把这一部分当作本书对前面每一部分都隐含提出的那个问题的回答来阅读：既然你已经知道该衡量什么、该如何诚实地衡量它，你要如何真正构建起一个能够可持续地、大规模地做到这一点的组织，而不让整个努力在主题 1.2 从第一页起就警告过的那种操纵压力下崩溃。
